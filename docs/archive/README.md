# Documentation Archive

Archived docs are retained for historical reference only. They are not the current implementation source of truth for Phase 11 and should not be read for normal Codex tasks.

Use archived docs only when:

- an exact live error string points to an old path,
- a regression requires historical comparison,
- the user explicitly asks for historical context, or
- the task is specifically about migration/history.

Current Phase 11 source of truth starts with:

- `docs/CODEX_ACTIVE_CONTEXT.md`
- `AGENTS.md`
- `docs/ARCHITECTURE.md`

Apps Script and Phase 6 materials in this archive describe retired or historical work. Apps Script is not the intended Phase 11 sync path.
